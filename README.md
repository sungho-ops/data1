# 📊 과제물1: 산업연관표 분석 웹앱

한국은행에서 발행한 **2022~2024년 투입산출표(기본부문, 380개 산업)**를 기반으로 거시경제 지표를 분석하고, 특정 산업의 수요 충격이 전체 경제에 미치는 파급 효과를 시뮬레이션하는 웹 기반 데이터 분석 애플리케이션입니다.

---

## 📌 주요 분석 기능 및 분석 방법

이 웹앱은 크게 4가지의 산업연관분석(Input-Output Analysis) 기능을 제공합니다.

### 1. 원자료 탐색 (Raw Data Explorer)
* **분석 방법:** 한국은행이 공표한 투입산출표 원자료(A표_총거래표, 국산거래표, 수입거래표 등) 및 각종 유발계수표를 시트별, 산업별로 조회합니다.
* **사용법:** 
  1. 상단의 '분석 연도'를 선택하고 **[기본부문 불러오기]** 버튼을 클릭하여 데이터를 로드합니다.
  2. 조회하고자 하는 시트와 행/열(산업명 또는 코드)을 검색하여 원자료 값을 확인합니다.

### 2. 국내 생산물 최종수요 증가 시뮬레이션
* **분석 방법:** 레온티예프 역행렬(생산유발계수)을 활용하여 특정 산업에 새로운 최종수요(투자, 수출, 소비 등)가 발생했을 때, 경제 전체에 미치는 직·간접적인 파급효과(생산유발액, 부가가치유발액, 수입유발액)를 추정합니다.
* **사용법:**
  1. 충격이 발생하는 산업을 검색하여 선택합니다.
  2. 수요 증가액을 입력하고 **[시나리오 추가]**를 누릅니다. (여러 산업 복수 선택 가능)
  3. **[계산하기]** 버튼을 누르면 전체 산업에 미치는 파급효과가 바 차트 및 데이터 표 형식으로 시각화되어 출력됩니다.
  4. 도출된 결과는 **[CSV 다운로드]** 버튼을 통해 엑셀에서 추가 분석이 가능합니다.

### 3. 전방 및 후방 연쇄효과 분석 (핵심산업 도출)
* **분석 방법:** 라스무센(Rasmussen) 지수를 활용하여 각 산업의 영향력계수(후방연쇄효과)와 감응도계수(전방연쇄효과)를 도출합니다.
  * **후방연쇄효과(영향력계수):** 해당 산업의 최종수요가 1단위 증가할 때 전 산업에 미치는 생산유발 정도 (1 이상일 경우 평균 이상).
  * **전방연쇄효과(감응도계수):** 전 산업의 최종수요가 각각 1단위 증가할 때 해당 산업이 받는 생산유발 정도 (1 이상일 경우 평균 이상).
* **사용법:** **[핵심 산업 분석하기]** 버튼을 누르면 380개 전 산업의 계수를 계산하며, 두 계수가 모두 1.0 이상인 산업은 **'⭐ 핵심산업'**으로 자동 분류되어 표시됩니다.

### 4. 연도별 트렌드 비교 (2022~2024 시계열 분석)
* **분석 방법:** 특정 산업의 전방·후방 연쇄효과가 최근 3년간 어떻게 변화해 왔는지 시계열로 추적하여, 해당 산업의 경제적 위상 변화를 분석합니다.
* **사용법:** 분석하고자 하는 산업을 검색/선택한 후 **[트렌드 분석하기]** 버튼을 누르면 백그라운드에서 3개년 데이터를 순차적으로 처리하여 변화 추이를 표로 제시합니다.

## 💡 데이터 및 단위 안내

* **데이터 출처:** 한국은행 경제통계시스템(ECOS) 투입산출표 (기본부문 380개 기준)
* **금액 단위:** 본 웹앱에서 사용되는 모든 금액표(거래표, 수요 증가액, 유발액 등)의 기본 단위는 **백만원(￦)**입니다.
* **지수 단위:** 각종 유발계수, 영향력계수, 감응도계수는 단위가 없는 순수 지수(Index) 및 비율(Ratio)입니다.
* **보안 및 권한:** 본 데이터는 누구나 접근 및 활용 가능한 공공데이터이며, 민감한 개인정보를 포함하지 않습니다.
